## What is a Network?

- Also called <span style="color:#e07b39">computer network</span>: 2 or more devices that need to share information between them
- To do that, you need a <span style="color:#3b82f6">common media</span> between them to share this information

## Network Types

### <span style="color:#e07b39">Local Area Network (LAN)</span>

- Users in the same room/department connected with a <span style="color:#3b82f6">switch</span> device
- Or users in different rooms/departments connected with a <span style="color:#3b82f6">router</span> and some switches

### <span style="color:#e07b39">Wide Area Network (WAN)</span>

- Users connected globally through the <span style="color:#3b82f6">internet</span>
- A <span style="color:#3b82f6">service provider</span> will be needed
- A group of devices (<span style="color:#3b82f6">routers</span>, <span style="color:#3b82f6">switches</span>, etc.) will be needed

## Network Components

<span style="color:#e07b39">routers</span> : network devices that connect different <span style="color:#3b82f6">network domains</span> and routes every <span style="color:#3b82f6">IP packet</span> to the correct destination

* each interface is a <span style="color:#3b82f6">broadcast domain</span>(network)

<span style="color:#e07b39">switches</span> : a network device that connects 2 or more devices in one <span style="color:#3b82f6">network domain</span>

<span style="color:#e07b39">multi-layer switch</span> is a device that behaves like a normal switch but can also route

<span style="color:#e07b39">Firewalls</span> and <span style="color:#e07b39">intrusion prevention systems</span> :

* firewalls protect you from the internet
* apply some restrictions to your local network (Example: <span style="color:#22c55e">A company uses a firewall to block employees from accessing social media</span>)
* <span style="color:#e07b39">intrusion prevention systems (IPS)</span> perform <span style="color:#3b82f6">deep packet inspection (DPI)</span>
* try to spot attacks

there is also a 2 in 1 solution called <span style="color:#e07b39">next generation firewalls (NGFW)</span> = FW + IPS

<span style="color:#e07b39">Access points</span> : same as switches, <span style="color:#3b82f6">APs</span> are the wireless destination for a host (user) to communicate with another host

<span style="color:#e07b39">controllers</span> :

A: <span style="color:#3b82f6">wireless controllers(WLC)</span> is a central management point for multiple APs

B: <span style="color:#3b82f6">Cisco DNA center</span> : powerful central point of management for :

1. analytics
2. automation
3. using <span style="color:#3b82f6">GUI</span> to design, display, and configure

<span style="color:#e07b39">servers</span> : a device that stores common data for users to make use of

information about packets : https://www.cloudflare.com/learning/network-layer/what-is-a-packet/




## Network Topologies

### Bus Topology

All devices are connected to a <span style="color:#e07b39">single shared backbone cable</span>.

* Advantages: Low cost, uses less cable.
* Disadvantages: If the <span style="color:#3b82f6">backbone cable</span> fails, the entire network can be affected. Troubleshooting can be difficult.
* picture to reference : https://edrawmax.wondershare.com/templates/Network/bus-topology-network-diagram.jpg

### Star Topology

All devices (or switches) connect to a <span style="color:#e07b39">central device</span>, usually a <span style="color:#3b82f6">switch</span>.

* Advantages: Easy to manage and troubleshoot. A single device's cable failure usually affects only that device.
* Disadvantages: If the central switch fails, connected devices lose network connectivity.
* picture to reference : https://d2cest1yk6hx2d.cloudfront.net/uninets-001/store/3057/article%20images/star%20topology%20(1).png

### Full Mesh Topology

Every device has a <span style="color:#e07b39">direct connection to every other device</span>.

* Advantages: High <span style="color:#3b82f6">redundancy</span> and multiple paths between devices.
* Disadvantages: Expensive, requires many connections, and is complex to maintain.
* picture to reference : https://networklessons.com/wp-content/uploads/2016/12/full-mesh-router-topology.png

### Partial Mesh Topology

<span style="color:#e07b39">Only some devices have direct connections</span> to each other, rather than every device being connected to every other device.

* Advantages: Provides <span style="color:#3b82f6">redundancy</span> at a lower cost than full mesh.
* Disadvantages: Some devices have fewer alternative paths, so certain link failures may interrupt connectivity.
* picture to reference : https://networklessons.com/wp-content/uploads/2016/12/partial-mesh-router-topology.png


## Enterprise Network Design

* simplify <span style="color:#3b82f6">scaling</span> and troubleshooting
* technologies should be distributed well based on <span style="color:#e07b39">layers/tiers</span>
* depends on your network size and future growth

### Tier 2 for small/mid networks

* one building network
* only 2 tiers (<span style="color:#e07b39">access</span> and <span style="color:#e07b39">aggregation</span> (<span style="color:#3b82f6">distribution</span>))

<span style="color:#e07b39">access</span> :

* is the first layer that faces/authenticates <span style="color:#3b82f6">endpoint devices</span>
* connects the endpoints to their <span style="color:#3b82f6">gateways</span> (aggregation)

<span style="color:#e07b39">aggregation</span> :

* aggregates/communicates all the access layers
* runs both <span style="color:#3b82f6">layer2</span> and <span style="color:#3b82f6">layer3</span> technologies and protocols
* runs in pair device mode (<span style="color:#3b82f6">SSO</span>)
