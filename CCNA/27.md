# The Transportation Layer (layer 4)

in the layer 3 of the OSI model you have packet and inside that packet you have protocol section , in that section you say what protocol you will use ,  this part can contain 255 protocol , other protocols is in the 4th layer (transportation) , there you can choose TCP = 6 or UDP = 17

after you go up to layer 4 , the layer 4 data is segment(for TCP) or diagram(for UDP) and inside this data you have (Destination Port) part , and inside that part you will set the protocol number you will use 

# TCP VS UDP
### TCP
* HTTP = TCP80
* HTTPS = TCP443
* FTP = TCP20, 21
* SSH = TCP22
* Telnet = TCP23
* SMTP = TCP25
* BGP = TCP179

### UDP
* SNMP = UDP161
* TFTP = UDP69
* DNS = USP53
* SYSLOG = UDP514

# - Transmission Communication Protocol & User Datagram Protocol
- Multiplexing at layer 4
- for multi-transmission of different techs. At the same time
- protocols can be
  - Reliable, connection-oriented, perform the 3-way handshake
    - TCP
  - Unreliable, connection-less, direct transmission
    - UDP
- some technologies considers the same port of both the protocols
- which by most, are taken from the well-known domain (0-1023)
