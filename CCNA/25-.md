# Classless Inter Domain Routing (CIDR) :
- design a subnet mask
- based on the need
	- need for amount of address space
	- factor of safety(future growth)
	- appropriate isolation
	- careful with summarization

So now you need to design the subnet mask , you will get a number of hosts or endpoints
and you need to know what is the best subnet mask for this number of hosts , 

for example if you have a building that have 4 floors
the first need 50 host
the second need 14
the third need 30
the fourth need 5

for best practice you need to design from the bigger to the smaller hosts , so like 50-30-14-5

now you need to make a stair of Multiples , like this :
1-2-4-8-16-32-64-128-256-512-1024-2048....
then you need to stop at the number that can contain your need for host so if our need now is 50 host we will stop at 64 , all the numbers before 64 is the zeros of the subnet mask , so now we have 6 zeros ,

to get the subnet mask you need to subtract 32-6 = 26(that is our subnet)
the increment value is the same number we stopped at the stairs (64)![[Screenshot_50.png]]

So , for the next floor the Network ID will be 192.108.1.64 , because the first floor ended with 63
