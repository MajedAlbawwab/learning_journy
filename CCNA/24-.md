# The MAC Address
used to identify a network interface on a local network.
When PC A sends data to PC B, it puts PC B's MAC address in the Ethernet frame's destination MAC field.
The switch reads that address and forwards the frame to PC B's port

- layer 2 technology
- Hexa-Decimal language
- physical address
- constant and unique
- 48 bit length
- half for the organization half for the product![[Pasted image 20261029120507.png]]


# Internet Protocol version 4 (IPv4)
IPv4 is a Layer 3 (Network Layer) protocol that provides logical addressing and enables packets to be routed between networks.

- layer 3 technology
- Decimal language (converted to binary then)
- logical address
- variable , based on the need
- 32 bit length
- part for the network , part for the host
- 4 Octests
each part for the ip address contain 8 bit
and the range of number in a part is 0-255


### What is subnetting?

Subnetting means splitting one large IP network into smaller networks (subnets). You do this by borrowing bits from the host portion of an IP address and using them as extra network bits.
- from 8 -32
- the smallest , the bigger
- /XX or XXX.XXX.XXX.XXX like the ip address

### What is a subnet mask?

A subnet mask is a 32-bit value that marks which bits of an IP address are the **network** part and which are the **host** part:
