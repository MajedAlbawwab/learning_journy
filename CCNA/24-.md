# The MAC Address
used to identify a network interface on a local network.
When PC A sends data to PC B, it puts PC B's MAC address in the Ethernet frame's destination MAC field.
The switch reads that address and forwards the frame to PC B's port

- layer 2 technology
- Hexa-Decimal language
- physical address
- constant and unique
- 48 bit length
- half for the organization half for the product![[Pasted image 20261029120507.png]]
