## The MAC Address

<span style="color:#e07b39">used to identify a network interface</span> on a local network.

When <span style="color:#22c55e">PC A sends data to PC B</span>, it puts PC B's MAC address in the <span style="color:#3b82f6">Ethernet frame</span>'s <span style="color:#3b82f6">destination MAC</span> field.

The <span style="color:#3b82f6">switch</span> reads that address and forwards the frame to PC B's port

* <span style="color:#3b82f6">layer 2</span> technology
* <span style="color:#3b82f6">Hexa-Decimal</span> language
* <span style="color:#e07b39">physical address</span>
* constant and unique
* <span style="color:#3b82f6">48 bit</span> length
* half for the organization half for the product

## Internet Protocol version 4 (IPv4)

<span style="color:#e07b39">IPv4</span> is a <span style="color:#3b82f6">Layer 3</span> (Network Layer) protocol that provides <span style="color:#e07b39">logical addressing</span> and enables packets to be routed between networks.

* <span style="color:#3b82f6">layer 3</span> technology
* Decimal language (converted to binary then)
* <span style="color:#e07b39">logical address</span>
* variable, based on the need
* <span style="color:#3b82f6">32 bit</span> length
* part for the network, part for the host
* 4 <span style="color:#3b82f6">Octets</span>

each part of the ip address contains 8 bit

and the range of number in a part is 0-255

## What is subnetting?

<span style="color:#e07b39">Subnetting</span> means splitting one large IP network into smaller networks (subnets). You do this by borrowing bits from the <span style="color:#3b82f6">host portion</span> of an IP address and using them as extra <span style="color:#3b82f6">network bits</span>.

* from 8 - 32
* the smallest, the bigger
* /XX or XXX.XXX.XXX.XXX like the ip address

## What is a subnet mask?

A <span style="color:#e07b39">subnet mask</span> is a <span style="color:#3b82f6">32-bit</span> value that marks which bits of an IP address are the network part and which are the host part:

### Variable-Length subnet mask (VLSM)

* much more economic for the use of subnetting
* can obtain:
    * <span style="color:#e07b39">Network ID</span>
    * Network address range
    * <span style="color:#e07b39">Broadcast ID</span>

the subnet mask is the number after the /

the ones are the <span style="color:#3b82f6">network portion</span> and the zeros are the <span style="color:#3b82f6">host portion</span>

the ip itself is called the <span style="color:#e07b39">Network ID</span>

you take the subnet mask number and subtract it from 32, you will take the answer and put it in power of two

the result will be the <span style="color:#e07b39">increment value</span>

you take one from it because in the ip the 0 will count as one

the result will be the <span style="color:#e07b39">broadcast</span> ip and anything in between will be the range
