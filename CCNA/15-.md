#  On-Premise Networks

Definition: An on-premises network is a network whose infrastructure is hosted at the organization's own physical location, such as its office or data center.

Key characteristics:

- The organization manages its own network infrastructure.
    
- Uses physical devices such as routers, switches, firewalls, and servers.
    
- Provides direct control over hardware and network configuration.
    
- Requires maintenance, space, power, and hardware costs.
    

Example: A company has its own servers and Cisco switches inside its office building.

# Cloud Networks

Cloud computing provides IT services on demand using resources that can be scaled as needed, rather than requiring an organization to own all the underlying physical infrastructure.

## On-premises vs. cloud

| Feature           | On-premises network                                      | Cloud network                                                                                                  |
| ----------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Definition        | Infrastructure hosted at the organization's own location | Infrastructure and services hosted in a cloud provider's environment                                           |
| Physical hardware | Organization manages its physical network equipment      | Cloud provider manages the underlying physical infrastructure                                                  |
| Scaling           | Often requires purchasing and installing hardware        | Resources can often be provisioned or scaled on demand                                                         |
| Maintenance       | Organization maintains its own infrastructure            | Provider maintains the underlying infrastructure; customer still manages its cloud configuration and resources |
| Example           | Servers and Cisco switches inside an office              | Virtual servers and networks hosted by a cloud provider                                                        |
