#  # <span style="color:#e07b39">On-Premises Networks</span>

Definition: An <span style="color:#e07b39">on-premises network</span> is a network whose infrastructure is hosted at the organization's own physical location, such as its office or data center.

Key characteristics:

- The organization manages its own <span style="color:#3b82f6">network infrastructure</span>.
- Uses physical devices such as <span style="color:#3b82f6">routers</span>, <span style="color:#3b82f6">switches</span>, <span style="color:#3b82f6">firewalls</span>, and <span style="color:#3b82f6">servers</span>.
- Provides direct control over hardware and network configuration.
- Requires maintenance, space, power, and hardware costs.

Example: <span style="color:#22c55e">A company has its own servers and Cisco switches inside its office building.</span>

# <span style="color:#e07b39">Cloud Networks</span>

<span style="color:#e07b39">Cloud computing</span> provides IT services <span style="color:#3b82f6">on demand</span> using resources that can be <span style="color:#3b82f6">scaled</span> as needed, rather than requiring an organization to own all the underlying physical infrastructure.

## On-premises vs. cloud

| Feature           | On-premises network                                                                                | Cloud network                                                                                                                                                                       |
| ----------------- | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Definition        | <span style="color:#e07b39">Infrastructure hosted at the organization's own location</span>        | <span style="color:#e07b39">Infrastructure and services hosted in a cloud provider's environment</span>                                                                              |
| Physical hardware | Organization manages its physical network equipment                                                | Cloud provider manages the underlying physical infrastructure                                                                                                                         |
| Scaling           | Often requires purchasing and installing hardware                                                  | Resources can often be <span style="color:#3b82f6">provisioned</span> or scaled on demand                                                                                            |
| Maintenance       | Organization maintains its own infrastructure                                                      | Provider maintains the underlying infrastructure; customer still manages its <span style="color:#3b82f6">cloud configuration</span> and resources                                   |
| Example           | <span style="color:#22c55e">Servers and Cisco switches inside an office</span>                     | <span style="color:#22c55e">Virtual servers and networks hosted by a cloud provider</span>                                                                                           |
